Finility: News Sentiment, VIX & S&P 500 Returns (2017–2020)

This project analyzes whether daily financial news sentiment can help explain or predict movements in the S&P 500 index.

It combines ~50,000 headlines from major news outlets with S&P 500 market returns and VIX volatility data.

DATA SOURCES

Financial News Headlines (CNBC, Guardian, Reuters)
Source: https://www.kaggle.com/datasets/notlucasp/financial-news-headlines

Type: Manual download (CSV)
Fields: date, headline, description, time
How used: Saved as three CSV files in the local data/ folder.

S&P 500 Index (^GSPC)
Source: https://finance.yahoo.com

Access: API via yfinance (downloaded in code)
Fields: Date, Open, High, Low, Close, Volume
How used: Saved automatically as data/sp500_2017_2020.csv.

VIX Volatility Index (^VIX)
Source: https://finance.yahoo.com

Access: API via yfinance (downloaded in code)
Fields: Date, Open, High, Low, Close, Volume
How used: Saved automatically as data/vix_2017_2020.csv.

IMPORTANT – MANUAL KAGGLE DOWNLOAD

All other files (S&P 500, VIX, daily sentiment, merged dataset) are automatically generated by the pipeline.

RESULTS SUMMARY

Key findings:

Daily news sentiment (same-day or lagged) has weak predictive power for S&P 500 daily returns.

VIX (market volatility) has a meaningful negative relationship with returns (higher volatility is associated with more negative returns).

Correlation patterns:

Sentiment vs Return: very weak positive

VIX vs Return: weak negative

Sentiment vs VIX: moderate negative (fearful markets often show negative news tone)

Linear regression achieves R² of about 0.027, which is realistic for noisy financial time series.

INSTALLATION

Create environment variables

Create a file:

src/.env

based on:

src/.env.example

No API keys are required unless you want to use the Kaggle API to download news.

Install dependencies

Run:

pip install -r requirements.txt

RUNNING THE FULL PIPELINE

From the project root (the folder that contains src/, doc/, results.ipynb, etc.), run:

python -m src.main

This will:

Download S&P 500 and VIX data using yfinance

Load and clean the Kaggle news CSVs from data/

Train a sentiment classifier (Linear SVC) using VADER labels

Predict sentiment for all headlines

Aggregate sentiment to daily scores

Merge daily sentiment, S&P 500 returns, and VIX into one file:

data/merged_sentiment_market.csv

This merged CSV is the input for the final analysis.

FINAL ANALYSIS

Once the pipeline has run successfully, open the notebook:

results.ipynb

This notebook:

Loads the merged dataset (from MERGED_DATA_CSV in config.py)

Produces visualizations and summary statistics

Fits regression models and reports coefficients, p-values, and R²

Generates all plots used in the final presentation

results.ipynb is the main final results artifact.

TESTS

To verify that market data loading works correctly, run:

python -m src.tests

This executes at least one test for the data loading functions (e.g., get_market_data).
